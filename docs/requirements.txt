# What Read the Docs installs to build the site. See .readthedocs.yaml.
#
# Minimum floors, not a pip-compile lock. The previous version of this file was
# a full transitive lock compiled in 2022 against Python 3.10, and it rotted:
# it pinned mkdocs 1.3.0, Markdown 3.3.7 and pymdown-extensions 9.5, which
# between them accounted for four open Dependabot alerts on the default branch.
# A docs build is not something a lock buys much for — if mkdocs breaks the
# build, `mkdocs build --strict` says so immediately — and floors do not need
# re-compiling every time an unrelated CVE lands.
#
# mkdocstrings[python] used to be here. Nothing referenced it: mkdocs.yml loads
# only the `search` plugin and no page uses a `:::` autodoc directive. It was
# also the sole thing pulling in pymdown-extensions, hence three of the four
# alerts. Removed rather than bumped.
#
# The extensions mkdocs.yml asks for are `markdown_include.include`, which is
# markdown-include, and `admonition`, which ships with Markdown itself.

mkdocs>=1.6
markdown-include>=0.8
